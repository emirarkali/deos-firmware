# deos_core_proto

Minimal Zephyr application.

## Board

Board configuration is stored in:

```text
board.txt
```

Example:

```text
nucleo_f303re
```

## Build

```bash
zephyrproject -build
```

## Clean Build

```bash
zephyrproject -clean
```

## Build and Flash

```bash
zephyrproject -flash
```

## Clean Build and Flash

```bash
zephyrproject -clean-flash
```

## Flash Only

```bash
zephyrproject -flash-only
```

## Debug

```bash
zephyrproject -debug
```
